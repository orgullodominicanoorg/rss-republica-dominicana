# RSS de República Dominicana

Directorio técnico y abierto de fuentes RSS relacionadas con República
Dominicana. Está pensado para periodistas, investigadores, bibliotecas,
lectores de la diáspora y cualquier persona que quiera seguir varias fuentes
sin depender del algoritmo de una red social.

La lista se mantiene como un archivo OPML importable en lectores como Feedly,
Inoreader, NewsBlur, NetNewsWire y aplicaciones compatibles:

- [Descargar `republica-dominicana.opml`](republica-dominicana.opml)
- [Abrir la versión web](https://orgullodominicanoorg.github.io/rss-republica-dominicana/)

## Criterios técnicos

Cada feed incluido fue comprobado el 29 de octubre de 2026. En ese momento:

1. respondía HTTP 200;
2. entregaba XML RSS legible;
3. contenía al menos un elemento publicado; y
4. pertenecía al dominio público de la fuente identificada.

La inclusión solo confirma que el canal funcionaba durante la comprobación. No
constituye un aval editorial, una clasificación de confiabilidad ni una
afirmación sobre la exactitud de cada publicación. Cada fuente conserva la
responsabilidad sobre su contenido.

## Mantenimiento

Este recurso es mantenido por
[Orgullo Dominicano](https://orgullodominicano.org/), periódico digital sobre
República Dominicana y su diáspora. Las correcciones técnicas pueden proponerse
mediante los *issues* de este repositorio.
